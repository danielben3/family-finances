# 🏦 מערכת ניהול פיננסי משפחתי (Family Financial OS)

מערכת Web ו-PWA מתקדמת, נקייה ומודרנית לניהול כלכלת המשפחה, מעקב תזרים חודשי וצמיחת שווי ההון הכולל.
מבוססת על נתוני קובץ האקסל המקורי (`מעקב הוצאות.xlsx`) עם סנכרון ענן בזמן אמת דרך **Supabase**.

---

## ✨ תכונות עיקריות
1. **תמונת מצב הון כולל (Net Worth Hero):**
   - שווי כולל עדכני ופילוח נכסים גרפי: עו"ש, אלטשולר שחם (גמל), אקסלנס (מניות), וקרן כספית.
   - חישוב אוטומטי של דלתא (שינוי בשקלים ובאחוזים) מחודש קודם.

2. **מעקב תזרים חודשי (Cash Flow KPIs):**
   - משכורות נטו, סך הוצאות שוטפות, חיסכון חודשי ואחוז חיסכון מהכנסה.

3. **טופס הזנה ועריכה חכם (Smart Input):**
   - תמיכה בחישוב נוסחאות בזמן אמת (למשל הזנת `=1500+430` או `26000+2044`).
   - חישוב חי של סך ההשקעות, שווי ההון הכולל ושיעור החיסכון.
   - שמירה מיידית מקומית וסנכרון לענן בלחיצה אחת.

4. **גרף צמיחת הון רב-שנתי (Wealth Analytics):**
   - גרף שטח אינטראקטיבי המציג את מגמת הצמיחה מאוגוסט 2024 ועד היום.
   - אפשרות מעבר בין תצוגת שווי כולל לתצוגת שכבות מפורטת של כל נכס.

5. **טבלה היסטורית מלאה וייצוא לאקסל:**
   - צפייה בכל 25 החודשים עם חלוקה לפי שנים (2024, 2025, 2026).
   - לחיצה על כל שורה טוענת את נתוני אותו חודש לטופס העריכה.
   - כפתור **ייצוא לאקסל (.xlsx)** להורדת גיבוי מלא ומעוצב ישירות למחשב.

6. **סנכרון ענן וגישה מהסמארטפון (Mobile PWA & Realtime):**
   - סנכרון בזמן אמת ב-WebSocket מול Supabase: שינוי שמבוצע במחשב מופיע מיד בטלפון של בן/בת הזוג.
   - מותאם במלואו למובייל עם טאבים תחתונים נוחים.
   - חלון קוד QR לסריקה קלה מהטלפון והתקנה כאפליקציה במסך הבית (Add to Home Screen).

## 🚀 איך מפעילים?

### הפעלה מהירה בלחיצה אחת (Windows):
פשוט לוחצים לחיצה כפולה על הקובץ:
👉 **`Start-Family-Finances.bat`**

השרת יופעל והדפדפן ייפתח אוטומטית בכתובת:
`http://localhost:5173`

---

## ☁️ הפעלת מסד הנתונים בענן (Supabase)

1. היכנס ל-SQL Editor בפרויקט Supabase שלך:
   [https://supabase.com/dashboard/project/knrxuxggwrcgltyqlqrb/sql/new](https://supabase.com/dashboard/project/knrxuxggwrcgltyqlqrb/sql/new)
2. העתק את כל תוכן הקובץ `supabase_schema.sql` והדבק אותו בעורך.
3. לחץ על **Run**.
4. כעת, הפעל את פקודת ההעלאה של כל היסטוריית האקסל למסד הנתונים:
   ```powershell
   node scripts/upload_to_supabase.js
   ```
*(האפליקציה פועלת גם במצב מקומי ללא שום עיכוב, אך שלב זה מאפשר סנכרון בזמן אמת בין מכשירים שונים).*
